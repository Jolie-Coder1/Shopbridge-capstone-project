 ShopBridge – Multilingual Kitchen Products E-Commerce Platform

ShopBridge is a modern, multilingual e-commerce web application designed to make shopping for kitchen products simple, accessible, and convenient for customers from different language backgrounds.

The platform supports five languages: English, Kinyarwanda, Kiswahili, Arabic, and Chinese, helping customers explore kitchen products and navigate the shopping experience in their preferred language.

 Project Overview

ShopBridge is an online shopping platform focused exclusively on kitchen products, including cookware, kitchen utensils, appliances, and storage essentials.

One of its main goals is to reduce language barriers in online shopping by allowing customers to select their preferred language.

 Multilingual Support

ShopBridge supports five languages:

- English
- Kinyarwanda
- Kiswahili (Swahili)
- Arabic
- Chinese

Customers can switch between supported languages to make the shopping experience more accessible and user-friendly.

 Key Features

- Multilingual Interface: Supports English, Kinyarwanda, Kiswahili, Arabic, and Chinese.
- Language Switching: Customers can select their preferred language.
- Kitchen Products: Focused collection of kitchen essentials.
- Product Search: Search for kitchen products easily.
- Product Categories:Browse products by category.
- Shopping Cart:Add products and manage cart items.
- Modern User Interface: Clean and attractive shopping experience.
- Responsive Design: Designed for desktop, tablet, and mobile screens.
- Navigation:Home, About, and Contact sections.

 Getting Started

Follow these steps to run the project locally.

 1. Clone the repository

bash

git clone https://github.com/Jolie-Coder1/Shopbridge-capstone-project.git


 2. Open the project folder

bash

cd Shopbridge-capstone-project


 3. Install dependencies

bash

npm install


 4. Start the development server

bash

npm.cmd run dev


 5. Open the application

Visit the local URL displayed in your terminal, usually:

text

http://localhost:5173
