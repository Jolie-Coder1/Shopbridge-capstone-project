 Shopbridge – Kitchen Essentials E-Commerce Platform

Shopbridge is a modern e-commerce platform designed to make shopping for kitchen products simple, convenient, and accessible. It allows customers to explore kitchen essentials through a user-friendly online shopping experience.

Project Overview

Shopbridge aims to provide customers with an easy way to discover and shop for kitchen products online. The platform focuses on simplicity, accessibility, and a smooth shopping experience.

 Key Features

- Product Browsing: Explore a collection of kitchen products.
- Product Search: Find products easily.
- **Shopping Cart: Add, remove, and manage products.
- Multilingual Support: English and Kinyarwanda language options.
- Responsive Design: Accessible on desktop, tablet, and mobile devices.
- Modern User Interface: Clean and user-friendly shopping experience.
- Customer Support: Contact support through the provided helpline.

 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Visual Studio Code (recommended)

Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Jolie-Coder1/Shopbridge-capstone-project.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Shopbridge-capstone-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   ```text
   http://localhost:5173
   ```
